# UPI Reconciliation Project

## About
This repository contains a Java-based UPI reconciliation project developed using Spring Boot and Maven.

## Technologies Used
- Java
- Spring Boot
- Maven

## Project Structure
- `src/main` - Main application source code and resources.
- `pom.xml` - Maven project configuration and dependencies.

## Getting Started
1. Clone or download this repository.
2. Open the project in your preferred Java IDE.
3. Make sure Java and Maven are configured.
4. Review the application configuration before running the project.
5. Run the Spring Boot application using your IDE or Maven.
